# Muhammad Aditya Novaldy — Portofolio

Portofolio dibangun dengan React + Vite.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build   # output ke dist/
npm run preview # cek hasil build secara lokal
```

## Deploy

Push ke branch `main` otomatis build & deploy ke GitHub Pages lewat
`.github/workflows/deploy.yml`. Sebelum push pertama kali, aktifkan dulu:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.
